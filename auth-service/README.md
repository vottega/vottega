# auth-service

> Vottega 마이크로서비스 아키텍처에서 **인증/인가(Auth)** 관련 기능을 담당하는 서비스입니다.  
> Spring Webflux 기반이며, Docker Compose로 컨테이너 실행을 지원합니다.  

## ✨ 주요 기능
- 사용자 인증(로그인) 및 토큰 발급/검증

---

## 🧱 기술 스택
- **언어:** Kotlin
- **프레임워크:** Spring Boot 3.3.2 + Webflux
- **문서화:** Swagger 주소 : /auth/api

---

## 🚀 빠른 시작(Quick Start)

### 로컬 실행 
docker-compose up -d --build
